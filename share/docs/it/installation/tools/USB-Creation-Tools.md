# Strumenti per la creazione USB

MiniOS può essere installato su una chiavetta USB utilizzando diversi strumenti a seconda del tuo sistema operativo.

## Strumenti consigliati

### 🖥️ Windows

- **[Rufus](/installation/tools/Rufus.md)** - Affidabile e versatile. Consigliato per la maggior parte degli utenti.
- **[Balena Etcher](/installation/tools/Balena-Etcher.md)** - Interfaccia semplice, multipiattaforma e moderna.
- **[Ventoy](/installation/tools/Ventoy.md)** - Permette di inserire più file ISO su una sola unità senza doverla riformattare.

### 🐧 Linux

- **[Comando dd](/installation/tools/dd.md)** - Strumento universale da riga di comando. Veloce e preinstallato sulla maggior parte delle distribuzioni.
- **[Balena Etcher](/installation/tools/Balena-Etcher.md)** - Interfaccia grafica intuitiva.
- **[Metodo originale](/installation/tools/Original-Method.md)** - Utilizzando gli strumenti standard di Linux (`cp`, `tar`).

### 🍎 macOS

- **[Balena Etcher](/installation/tools/Balena-Etcher.md)** - Il modo più semplice per gli utenti Mac.
- **[Comando dd](/installation/tools/dd.md)** - Per utenti esperti che hanno dimestichezza con il terminale.

## Altri strumenti

- **[UNetbootin](/installation/tools/UNetbootin.md)** - Uno strumento classico, a volte meno affidabile con le ISO più recenti.
- **[Drive Utility](/installation/tools/Drive-Utility.md)** - GNOME Disks o altre utility integrate simili.
