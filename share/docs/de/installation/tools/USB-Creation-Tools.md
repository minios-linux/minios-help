# USB-Erstellungstools

MiniOS kann mithilfe verschiedener Tools, abhängig vom Betriebssystem, auf ein USB-Laufwerk installiert werden.

## Empfohlene Tools

### 🖥️ Windows

- **[Rufus](/installation/tools/Rufus.md)** – Zuverlässig und vielseitig. Für die meisten Nutzer empfohlen.
- **[Balena Etcher](/installation/tools/Balena-Etcher.md)** – Einfach, plattformübergreifend, moderne Oberfläche.
- **[Ventoy](/installation/tools/Ventoy.md)** – Ermöglicht das Ablegen mehrerer ISOs auf einem Laufwerk ohne Neuformatierung.

### 🐧 Linux

- **[dd-Befehl](/installation/tools/dd.md)** – Universelles Kommandozeilen-Tool. Schnell und auf den meisten Distributionen vorinstalliert.
- **[Balena Etcher](/installation/tools/Balena-Etcher.md)** – Einfache grafische Oberfläche.
- **[Originalmethode](/installation/tools/Original-Method.md)** – Nutzung von Standard-Linux-Tools (`cp`, `tar`).

### 🍎 macOS

- **[Balena Etcher](/installation/tools/Balena-Etcher.md)** – Der einfachste Weg für Mac-Nutzer.
- **[dd-Befehl](/installation/tools/dd.md)** – Für fortgeschrittene Nutzer, die sich mit dem Terminal auskennen.

## Weitere Tools

- **[UNetbootin](/installation/tools/UNetbootin.md)** – Ein Klassiker, allerdings manchmal weniger zuverlässig mit modernen ISOs.
- **[Laufwerksdienstprogramm](/installation/tools/Drive-Utility.md)** – GNOME Disks oder ähnliche integrierte Tools.
