# Инструменты для создания USB

MiniOS можно установить на USB-накопитель с помощью различных инструментов в зависимости от вашей операционной системы.

## Рекомендуемые инструменты

### 🖥️ Windows

- **[Rufus](/installation/tools/Rufus.md)** — Надёжный и универсальный инструмент. Рекомендуется большинству пользователей.
- **[Balena Etcher](/installation/tools/Balena-Etcher.md)** — Простой, кроссплатформенный, современный интерфейс.
- **[Ventoy](/installation/tools/Ventoy.md)** — Позволяет размещать несколько ISO на одном накопителе без форматирования.

### 🐧 Linux

- **[dd command](/installation/tools/dd.md)** — Универсальный инструмент командной строки. Быстрый и предустановлен во многих дистрибутивах.
- **[Balena Etcher](/installation/tools/Balena-Etcher.md)** — Удобный графический интерфейс.
- **[Original Method](/installation/tools/Original-Method.md)** — Использование стандартных инструментов Linux (`cp`, `tar`).

### 🍎 macOS

- **[Balena Etcher](/installation/tools/Balena-Etcher.md)** — Самый простой способ для пользователей Mac.
- **[dd command](/installation/tools/dd.md)** — Для опытных пользователей, знакомых с терминалом.

## Другие инструменты

- **[UNetbootin](/installation/tools/UNetbootin.md)** — Классический инструмент, но иногда менее надёжен с современными ISO.
- **[Drive Utility](/installation/tools/Drive-Utility.md)** — GNOME Disks или аналогичные встроенные утилиты.
