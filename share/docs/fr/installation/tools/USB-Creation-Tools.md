# Outils de création USB

MiniOS peut être installé sur une clé USB à l’aide de différents outils selon votre système d’exploitation.

## Outils recommandés

### 🖥️ Windows

- **[Rufus](/installation/tools/Rufus.md)** – Fiable et polyvalent. Recommandé pour la plupart des utilisateurs.
- **[Balena Etcher](/installation/tools/Balena-Etcher.md)** – Simple, multiplateforme, interface moderne.
- **[Ventoy](/installation/tools/Ventoy.md)** – Permet de placer plusieurs ISO sur un même support sans le reformater.

### 🐧 Linux

- **[Commande dd](/installation/tools/dd.md)** – Outil universel en ligne de commande. Rapide et préinstallé sur la plupart des distributions.
- **[Balena Etcher](/installation/tools/Balena-Etcher.md)** – Interface graphique facile à utiliser.
- **[Méthode originale](/installation/tools/Original-Method.md)** – Utilisation des outils Linux standards (`cp`, `tar`).

### 🍎 macOS

- **[Balena Etcher](/installation/tools/Balena-Etcher.md)** – La solution la plus simple pour les utilisateurs Mac.
- **[Commande dd](/installation/tools/dd.md)** – Pour les utilisateurs avancés à l’aise avec le terminal.

## Autres outils

- **[UNetbootin](/installation/tools/UNetbootin.md)** – Un outil classique, parfois moins fiable avec les ISO récents.
- **[Drive Utility](/installation/tools/Drive-Utility.md)** – GNOME Disks ou autres utilitaires intégrés similaires.
