# Ferramentas para Criação de USB

O MiniOS pode ser instalado em um pendrive usando várias ferramentas, dependendo do seu sistema operacional.

## Ferramentas Recomendadas

### 🖥️ Windows

- **[Rufus](/installation/tools/Rufus.md)** - Confiável e versátil. Recomendado para a maioria dos usuários.
- **[Balena Etcher](/installation/tools/Balena-Etcher.md)** - Interface simples, moderna e multiplataforma.
- **[Ventoy](/installation/tools/Ventoy.md)** - Permite colocar múltiplos ISOs em um único drive sem precisar formatar.

### 🐧 Linux

- **[Comando dd](/installation/tools/dd.md)** - Ferramenta universal de linha de comando. Rápida e já vem instalada na maioria das distros.
- **[Balena Etcher](/installation/tools/Balena-Etcher.md)** - Interface gráfica fácil de usar.
- **[Método Original](/installation/tools/Original-Method.md)** - Usando ferramentas padrão do Linux (`cp`, `tar`).

### 🍎 macOS

- **[Balena Etcher](/installation/tools/Balena-Etcher.md)** - A maneira mais fácil para usuários de Mac.
- **[Comando dd](/installation/tools/dd.md)** - Para usuários avançados que já têm familiaridade com o terminal.

## Outras Ferramentas

- **[UNetbootin](/installation/tools/UNetbootin.md)** - Uma ferramenta clássica, embora às vezes menos confiável com ISOs mais recentes.
- **[Utilitário de Disco](/installation/tools/Drive-Utility.md)** - GNOME Disks ou outros utilitários nativos semelhantes.
