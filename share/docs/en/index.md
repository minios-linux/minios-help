# MiniOS Wiki

**Reliable and user-friendly portable Linux**

Built on Debian, offering flexibility for system recovery and daily use.

- **Portable**: Run from USB with persistent changes.
- **Modular**: Easy to customize with SquashFS modules.
- **Debian-based**: Stable and compatible foundation.
