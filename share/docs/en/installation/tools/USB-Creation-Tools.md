# USB Creation Tools

MiniOS can be installed to a USB drive using various tools depending on your operating system.

## Recommended Tools

### 🖥️ Windows
- **[Rufus](/installation/tools/Rufus.md)** - Reliable and versatile. Recommended for most users.
- **[Balena Etcher](/installation/tools/Balena-Etcher.md)** - Simple, cross-platform, modern interface.
- **[Ventoy](/installation/tools/Ventoy.md)** - Allows placing multiple ISOs on one drive without reformatting.

### 🐧 Linux
- **[dd command](/installation/tools/dd.md)** - Universal command-line tool. Fast and pre-installed on most distros.
- **[Balena Etcher](/installation/tools/Balena-Etcher.md)** - Easy graphical interface.
- **[Original Method](/installation/tools/Original-Method.md)** - Using standard Linux tools (`cp`, `tar`).

### 🍎 macOS
- **[Balena Etcher](/installation/tools/Balena-Etcher.md)** - The easiest way for Mac users.
- **[dd command](/installation/tools/dd.md)** - For advanced users comfortable with the terminal.

## Other Tools
- **[UNetbootin](/installation/tools/UNetbootin.md)** - A classic tool, though sometimes less reliable with modern ISOs.
- **[Drive Utility](/installation/tools/Drive-Utility.md)** - GNOME Disks or similar built-in utilities.
